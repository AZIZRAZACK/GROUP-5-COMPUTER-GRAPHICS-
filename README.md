# Group 5 — Computer Graphics Troll Platformer

A *Level Devil*-style troll platformer built with Vanilla JavaScript and HTML5 Canvas using a modular Slot architecture:
- **ViewSlot** (`src/slots/ViewSlot.js`): Camera pan, zoom, screen shake, and viewport inversion.
- **ClipSlot** (`src/slots/ClipSlot.js`): Circular spotlight masking and visual tile hiding.
- **FontSlot** (`src/slots/FontSlot.js`): Dynamic typography swaps and lethal falling taunt text.
